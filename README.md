# 📅 Smart Event Manager (C++)

A simple **console-based Event Management System** built using C++.  
This project allows users to create, manage, and analyze events efficiently with admin-controlled access.

---

## 🚀 Features

- 🔐 **Admin Authentication**
- ➕ **Add Event**
- ✏️ **Edit Event**
- ❌ **Delete Event**
- 📆 **View Events by Day**
- 🔍 **Search Event**
- 📊 **Analytics**
- 🔔 **Send Reminders**
- 💾 **Persistent Storage (events.csv)**

---

## 🛠️ Technologies Used

- C++
- STL (Vectors, Maps, Algorithms)
- File Handling (`fstream`)


---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- File Handling
- Searching & Sorting
- Data Validation
- Conflict Detection

---

## ⚠️ Limitations

- Basic date/time validation
- Console-based (no GUI)
- Hardcoded password
